## 🚀 เริ่มต้นใช้งาน (Getting Started)

### ขั้นตอนที่ 1: เปิด Repository บน GitHub Codespaces

1. ไปที่ Repository นี้บน GitHub: `https://github.com/codepassion-team/QuickTry-Workshop-Software-Engineer`
2. คลิกปุ่ม **Code** สีเขียว
3. เลือกแท็บ **Codespaces**
4. คลิก **Create codespace on main** เพื่อเปิด Workspace ออนไลน์
5. รอสักครู่จนกว่า VS Code จะเปิดขึ้นมาในเบราว์เซอร์

### ขั้นตอนที่ 2: ติดตั้ง Live Preview Extension

1. คลิกไอคอน **Extensions** ที่แถบด้านซ้าย (หรือกด `Ctrl+Shift+X` / `Cmd+Shift+X`)
2. พิมพ์ค้นหา **"Live Preview"**
3. หา Extension ที่ชื่อ **"Live Preview"** จาก Microsoft
4. คลิกปุ่ม **Install** เพื่อติดตั้ง
5. เมื่อติดตั้งเสร็จแล้ว คุณสามารถคลิกขวาที่ไฟล์ `.html` และเลือก **"Show Preview"** เพื่อดูตัวอย่างเว็บไซต์

### 🎉 เริ่มต้นเรียนรู้ได้เลย!

## 📚 เนื้อหาเวิร์คช็อป (Workshop Content)

### 1️⃣ พัฒนาทักษะพื้นฐาน (Skill Development)

**เส้นทางการเรียนรู้: เริ่มต้นจากศูนย์สู่การสร้างเว็บไซต์**

📁 โฟลเดอร์: `1-Basic-Web-Development`

เรียนรู้พื้นฐาน HTML, CSS และ JavaScript ผ่าน 14 บทเรียนที่ครอบคลุมทุกสิ่งที่คุณต้องรู้:

#### HTML Basics

- **101 - Hello World** - เริ่มต้นกับ HTML
- **102 - Headings** - การใช้หัวข้อ (h1-h6)
- **103 - Paragraph** - ย่อหน้าและข้อความ
- **104 - Links** - การสร้างลิงก์
- **105 - Images** - การแทรกรูปภาพ
- **106 - Buttons** - ปุ่มต่างๆ
- **107 - Lists** - รายการแบบมีลำดับและไม่มีลำดับ
- **108 - Text Formatting** - การจัดรูปแบบข้อความ
- **109 - Media** - การใช้สื่อมัลติมีเดีย (วิดีโอ, เสียง)
- **111 - Tables** - การสร้างตาราง

#### CSS & JavaScript

- **110 - Styling** - การตกแต่งด้วย Inline CSS
- **112 - CSS** - การใช้ CSS ขั้นสูง (External CSS)
- **113 - JavaScript** - พื้นฐาน JavaScript
- **114 - Forms** - การสร้างฟอร์มและจัดการข้อมูล

💡 **แนะนำ:** เรียนตามลำดับเพื่อความเข้าใจที่ดีที่สุด

### 3️⃣ ทำงานกับ GitHub (Work with GitHub)

**เรียนรู้การใช้ระบบควบคุมเวอร์ชัน**

#### สิ่งที่คุณจะได้เรียนรู้:

- 📦 สร้าง Repository แรกของคุณบน GitHub
- 📤 อัปโหลดโค้ดเว็บไซต์ของคุณ
- 🌐 เผยแพร่เว็บไซต์บน GitHub Pages
- 🤝 เรียนรู้การทำงานร่วมกันผ่าน Git
- 🔄 การจัดการ Version และ Branch

#### ขั้นตอนพื้นฐาน:

```bash
# Clone repository
git clone <your-repo-url>

# สร้างการเปลี่ยนแปลง
git add .
git commit -m "Your message"
git push origin main

# Deploy บน GitHub Pages
# Settings > Pages > Source: main branch
```

## ❓ คำถามที่พบบ่อย (FAQ)

### Q: ฉันไม่เคยเขียนโค้ดมาก่อน เริ่มต้นยังไงดี?

**A:** เริ่มจากโฟลเดอร์ `1-Basic-Web-Development` และเรียนตามลำดับตั้งแต่ 101-114 ครับ แต่ละบทเรียนสั้นและเข้าใจง่าย

### Q: ต้องติดตั้งโปรแกรมอะไรบ้าง?

**A:** ไม่ต้องติดตั้งอะไรเลย! ใช้ GitHub Codespaces ผ่านเบราว์เซอร์ได้เลย เพียงแค่ติดตั้ง Live Preview extension

### Q: ใช้เวลาเรียนนานแค่ไหน?

**A:** ขึ้นอยู่กับเวลาที่คุณมี แนะนำ:

- พื้นฐาน (Part 1): 3-4 ชั่วโมง
- ศึกษาตัวอย่าง (Part 2): 2-3 ชั่วโมง
- GitHub (Part 3): 1-2 ชั่วโมง
- สร้างโปรเจกต์ (Part 4): 2-3 ชั่วโมง

### Q: สามารถข้ามบางส่วนได้ไหม?

**A:** ได้ครับ แต่แนะนำให้เรียน Part 1 (พื้นฐาน) ให้จบก่อน จากนั้นสามารถเลือกเรียนตามความสนใจได้

### Q: เว็บไซต์ที่สร้างสามารถใช้งานจริงได้ไหม?

**A:** ได้เลยครับ! หลังจาก Deploy บน GitHub Pages แล้ว เว็บไซต์ของคุณจะออนไลน์และเข้าถึงได้จากทั่วโลก

### Q: ติดปัญหาต้องทำอย่างไร?

**A:** สามารถ:

- เปิด Issue ใน GitHub Repository นี้
- ดูตัวอย่างโค้ดในโฟลเดอร์ `2-Example-Works`
- ศึกษาเอกสารเพิ่มเติมจาก [MDN Web Docs](https://developer.mozilla.org/)

### Q: จบเวิร์คช็อปแล้วควรทำอะไรต่อ?

**A:**

- สร้างเว็บไซต์ของตัวเองด้วยเทมเพลต
- เรียนรู้ JavaScript Framework (React, Vue, etc.)
- ศึกษา Backend Development (Node.js, Python, etc.)
- ปรับปรุงและพัฒนาทักษะอย่างต่อเนื่อง
