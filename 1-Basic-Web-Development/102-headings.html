🤖 Prompt Skill กับ GitHub Copilot

เป้าหมายของบทนี้: ฝึกใช้ h1–h6 ผ่าน Copilot และเข้าใจลำดับชั้นหัวข้อที่ดีต่อ SEO

ตัวอย่าง Prompt ที่ดี:

  • // สร้างหน้าแนะนำตัวเอง ใช้ h1 เป็นชื่อ, h2 เป็นการศึกษา, h3 เป็นงานอดิเรก
  • /explain ทำไมในหน้าหนึ่งควรมี h1 เพียงอันเดียว
  • // แก้โค้ดด้านบนให้ semantic ถูกต้องตามหลัก SEO และ accessibility

⚠️ ข้อควรระวัง: อย่าใช้ heading เพื่อจัดขนาดตัวอักษรเฉย ๆ ให้ใช้ CSS แทน เพื่อรักษาโครงสร้าง semantic
