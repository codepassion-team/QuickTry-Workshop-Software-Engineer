เป้าหมายของบทนี้: ใช้ Copilot ช่วยสร้างโครงสร้าง HTML5 พื้นฐานและแสดงข้อความ Hello World!

ตัวอย่าง Prompt ที่ดี:

  • // สร้างไฟล์ HTML5 ที่ถูกต้อง มี doctype, html, head, body และแสดงข้อความ "Hello World!" ตรงกลางหน้าจอ
  • /explain โครงสร้าง HTML นี้ทำงานอย่างไร อธิบายเป็นภาษาไทยให้นักเรียน ม.ปลายเข้าใจ
  • // เพิ่ม comment อธิบายแต่ละ tag ให้ผู้เริ่มต้น

⚠️ ข้อควรระวัง: Copilot อาจเสนอ tag ที่เลิกใช้แล้ว เช่น <center> ให้ตรวจสอบกับ MDN Web Docs เสมอ
