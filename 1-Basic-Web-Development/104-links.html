HTML links are defined with the a tag:

This is a link
My Github

🤖 Prompt Skill กับ GitHub Copilot

เป้าหมายของบทนี้: สร้างลิงก์ภายในและภายนอกไซต์ได้อย่างปลอดภัย

ตัวอย่าง Prompt ที่ดี:

  • // สร้างเมนูนำทางที่มีลิงก์ไปหน้า Home, About, Contact
  • // เพิ่ม target="_blank" และ rel="noopener" ให้ลิงก์ที่ออกไปเว็บภายนอก
  • /explain ทำไมต้องใส่ rel="noopener" คู่กับ target="_blank"

⚠️ ข้อควรระวัง: Copilot อาจตั้ง href ไป URL ที่ไม่มีอยู่จริง ตรวจสอบทุกลิงก์ก่อน deploy
