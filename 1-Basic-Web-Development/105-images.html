HTML Images

HTML images are defined with the img tag:

🤖 Prompt Skill กับ GitHub Copilot

เป้าหมายของบทนี้: แทรกรูปภาพและเขียน alt text ที่ดีต่อ accessibility

ตัวอย่าง Prompt ที่ดี:

  • // เพิ่มรูป cat.jpg พร้อม alt text ที่อธิบายภาพให้ screen reader เข้าใจ
  • // ใส่ width 300 และทำให้รูปชิดกลางหน้า
  • /explain ความแตกต่างระหว่าง img กับ background-image ใน CSS

⚠️ ข้อควรระวัง: อย่าปล่อย alt ว่าง และอย่าผูก hotlink รูปจากเว็บอื่นโดยไม่ได้รับอนุญาต
