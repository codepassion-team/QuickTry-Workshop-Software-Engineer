เป้าหมายของบทนี้: ฝัง video/audio ที่เข้าถึงได้สำหรับทุกคน

ตัวอย่าง Prompt ที่ดี:

  • // เพิ่มแท็ก video เล่นไฟล์ sample.mp4 พร้อม controls และ poster image
  • // เพิ่ม audio เล่น music.mp3 พร้อม controls และ loop
  • /explain เหตุผลที่ควรเตรียมไฟล์หลายฟอร์มัต (mp4, webm) ใน source

⚠️ ข้อควรระวัง: ไฟล์มีเดียอาจขนาดใหญ่ แนะนำให้บีบอัดก่อน deploy และไม่ commit ลง git โดยตรง
